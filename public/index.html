🔗 ភ្ជាប់ Google Sheet តាម Apps Script (ងាយស្រួល ១ នាទី)

  1. បើក Google Sheet របស់អ្នក → ចុច Extensions → Apps Script
  2. ចម្លងកូដពី File google-apps-script/Code.gs ទៅដាក់ក្នុង Code.gs ហើយចុច Save
  3. ចុច Deploy → New deployment → Type: Web app (Execute as: Me, Who has access: Anyone)
  4. ចម្លង Web app URL មកដាក់ខាងក្រោម ហើយចុច Save & Test៖
